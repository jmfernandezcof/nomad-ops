# Security Policy

## Supported scope

This repository is a fictional, synthetic-data prototype. Security updates apply to the current `main` branch. The demo identity service and in-process simulator are not approved for production identities or real operational systems.

## Reporting a vulnerability

Please do not publish exploitable details, credentials or host information in a public issue. Use GitHub private vulnerability reporting through the repository's **Security** tab when available. If that option is unavailable, contact the repository owner privately and include only the minimum information needed to reproduce the issue.

Never include real secrets or personal data in a report. If a credential may have been exposed, revoke or rotate it before continuing the discussion.

## Deployment warning

Public source availability does not mean the application is ready for public hosting. Review `docs/security/publication-readiness.md` and complete its open deployment gates before exposing any route to the Internet.
